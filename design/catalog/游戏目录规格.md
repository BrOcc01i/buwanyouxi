# 不玩游戏 · 商店目录规格（18 款）

> 版本：v1 · 状态：待主理人评审 · 作者：文策渊（设计/叙事）
> 范围：把商店目录从 6 款扩到 18 款（新增 12 款），并给出分类体系、18+ 年龄门交互规格、命名合规自查、A/B/C 分批。
> 数据基线：`client/src/data/games.js`（6 款现有）· 状态键 `nw_client_state_v1`（内部 `version: 3`）。
> 本文只写设计规格，不改 `client/` 下任何代码。

---

## 0. 设计前提（先定三条，避免后面漂移）

1. **调性支柱：虚构、克制、略带冷幽默。** 不喊口号、不用营销体、不中二。钩子写「处境」，不写「卖点」——沿用现有 6 款的写法（例：「电梯只到 7 楼，而 7 楼不是这栋楼」）。
2. **类型可对齐，表达必须原创。** 12 款覆盖用户指定的 12 个类型锚点，但名称、世界观、钩子全部自造，禁止真实作品名/角色名/公司名的变体与谐音。
3. **一款一个「错位」**：每款都要有一个和同类作品错开的具体设定（马记性差、钟只敲一次、洗衣房是唯一的听众……），这是「合理性审视」的通过依据，也是不做中二感的保险。

### 3.3 筛选维度（三轴 + 一条排序）

| 维度 | 控件 | 取值 | 默认 | 落盘？ | 判定来源 |

| 18+ 内容 | 开关（默认开） | 显示 / 隐藏 | 显示 | **是**：`settings.showAdult` | `g.isAdult` 且 `settings.adultGate !== 'passed'` 时仍显示但点击走年龄门 |
| 是否已拥有 | 分段控件 | 全部 / 未拥有 / 已在库中 | 全部 | 否 | `state.library[id]` 存在即「已拥有」（含已安装/未安装/下载中） |

**组合规则**

- 三轴之间为 **AND**；同一轴内各自单选。
- 「已在库中」包含下载中的条目——用户会认为「正在下载的东西已经是我的」。
- **计数联动**：每个分类 tab 显示当前 `showAdult` 生效后的条数，如「恐怖 2」。隐藏态下「角色扮演」从 5 变 4，tab 数字必须实时变，否则用户会点进空页。
- **空态文案**（全目录最容易被忽略的地方）：「没有符合条件的作品。你的筛选项比游戏还严格。」+ 一个「重置筛选」按钮。
- **URL 不承载筛选状态**：路由仍是 `#/store`，刷新回到默认筛选，避免深链接与 18+ 隐藏态互相打脸。
- **搜索优先级**：搜索框与筛选是 AND；搜索命中 `name / tags / publisher`，**对隐藏的 18+ 条目直接不返回**（不做「结果被隐藏」提示，避免反向引导）。

### 3.4 已知结构风险

- **策略类目仅 1 款**：tab 里会出现「策略 1」的单品相。两个选项——(a) 接受，作为「类目完整性」的声明；(b) 把 C 批的某一款替换为战棋。**建议 (a)**，并在二期补第 2 款。
- **角色扮演 5 款偏多**（占 28%）：因为开放世界、叙事、roguelike 都归在此。若希望更均衡，可把「代签人」移入「休闲」——但它有强叙事与回溯，**不建议**，宁可接受不均衡。

## 4. 18+ 年龄门交互规格

### 4.1 设计原则

1. **门在「内容」前，不在「名字」前**：商店列表可以看到《同谋》的名字、类型、18+ 角标与一句克制的钩子，但看不到截图、长简介与获取按钮。
2. **只问一次，可反悔**：通过后本机永久记住；拒绝也可在设置里重新确认，不需要清空数据。
3. **安全默认**：弹窗初始焦点在「我还未满 18 岁」，Esc 与点遮罩 = 未表态（不记录、不处罚、下次照常问）。
4. **不采集、不上报**：不输入生日、不验证证件、不发任何请求；只存一个布尔判定与时间戳。

### 4.2 进入条件与触发点（三处，缺一即可被绕过）

| 触发点 | 条件 | 行为 |
|--------|------|------|
| ① 商店卡片点击 | `g.isAdult && settings.adultGate !== 'passed'` | 不跳转详情，就地弹年龄门（卡片区域降饱和 + 不可点） |
| ② 深链接 `#/detail/accomplice` | 同上 | 详情页渲染「受限占位页」（无截图、无简介、无获取按钮）+ 弹门 |
| ③ 获取/安装动作前断言 | `g.isAdult && adultGate !== 'passed'` | 兜底拦截，返回商店并弹门；用于防未来 UI 改造绕过 |

**通过后**：进入详情页正常浏览，`获取` 走既有 `openInstallDialog → startDownload` 流程，**不再二次弹门**。
**下载中/已安装的成人条目**：启动不再弹门（一次通过即视为本机成年确认）；库页不因 `showAdult` 隐藏（用户资产不可被筛掉）。

### 4.3 弹窗文案（主态）

- **标题**：`年龄确认`
- **正文**：

  > 《同谋》是一部 **18+ 虚构作品**：成人向恋爱悬疑题材，含成人情感关系描写。
  > 本客户端不提供任何露骨内容，此页仅用于演示分级与年龄门。
  > 请确认你已年满 18 岁。

- **按钮**：`我已满 18 岁`（次样式）/ `我还未满 18 岁`（主样式，默认焦点）

### 4.4 「未满 18 岁」分支的完整文案

点击后弹窗内容原位切换（不新开一层），文案：

- **标题**：`已按未满 18 岁处理`
- **正文**：

  > 《同谋》的封面、截图与获取入口将不再显示，也不会进入你的下载队列。
  > 这不是永久记录：你可以在「设置 → 体验 → 成人内容」里重新确认，或清除本地数据后重来。
  > 其余 17 款作品不受影响。

- **按钮**：`知道了`（唯一按钮，默认焦点）
- 关闭后：回商店页 → 该卡片即时消失（因 `showAdult` 被置 false）→ toast：`已按未满 18 岁处理`

### 4.5 Esc / 遮罩 / 关闭按钮

- 不写任何状态，关闭弹窗，停留商店（详情深链接场景则跳回 `#/store`）。
- 不做「你还没选择」的追问，不加二次确认——克制。

### 4.6 设置页入口（防绕过）

位置：`设置 → 体验` 分区，在「默认启动页面」之后新增一行。

| 行标签 | 状态值显示 | 点击行为 |
|--------|-----------|----------|
| 成人内容（18+） | 未确认 / 已通过 / 已限制（未满 18） | 未确认或已限制 → **再次弹年龄门**（通过则置 `passed` 并开启显示） |

- 该行的开关只控制 `showAdult`（商店显示与否），**不控制** `adultGate`；`declined` 状态下打开开关必须先过门。
- 文案脚注：`仅本机记录，不采集生日，不上传任何信息。`

### 4.7 `localStorage` 状态设计（兼容 `nw_client_state_v1`）

**存储位置**：仍为键 `nw_client_state_v1`，`version` 保持 `3`（与 v3 新增 `wallet/gifts` 同例：只加字段、不改结构，旧档读入自动补默认值）。**不新建顶层键**，避免与现有迁移/导出逻辑分叉。

```js
settings: {
  reducedMotion: false,
  soundEnabled: true,
  notificationsEnabled: true,
  defaultRoute: '#/store',
  // —— 新增（18+ 年龄门）——
  showAdult: true,        // boolean，默认 true；false = 商店/搜索隐藏全部 isAdult 条目
  adultGate: 'unset',     // 'unset' | 'passed' | 'declined'
  adultGateAt: null,      // number | null，判定时间戳（ms）
}
```

**`normalize()` 白名单补丁（三个字段，全部「类型不符即用默认」）**

```js
if (typeof s.showAdult === 'boolean') out.settings.showAdult = s.showAdult;
if (s.adultGate === 'passed' || s.adultGate === 'declined' || s.adultGate === 'unset') {
  out.settings.adultGate = s.adultGate;
}
if (typeof s.adultGateAt === 'number' && Number.isFinite(s.adultGateAt) && s.adultGateAt > 0) {
  out.settings.adultGateAt = s.adultGateAt;
}
```

**`updateSettings()` 补丁**：三个字段走 `typeof` 校验后浅合并（与现有 `reducedMotion` 写法一致）；`adultGate` 只接受三个枚举值，其余忽略。

**状态语义表**

| `adultGate` | `showAdult` | 商店表现 | 点击成人卡片 |
|-------------|-------------|----------|--------------|
| `unset` | true | 显示，带 18+ 角标 | 弹年龄门 |
| `unset` | false | 完全隐藏 | —（无处可点） |
| `passed` | true | 显示，带 18+ 角标 | 直接进详情 |
| `passed` | false | 完全隐藏（用户主动关） | —（可去设置重开） |
| `declined` | false | 完全隐藏 | —（可去设置重开） |
| `declined` | true | **非法组合**，写入时强制回 false | — |

**事件记录（沿用 `events` 数组，500 条上限内）**：`adult_gate_pass` / `adult_gate_decline` / `adult_toggle`（`extra: { showAdult }`）。清除本地数据后 `adultGate` 回到 `unset`（随 `settings` 一起重置，已有行为）。

**导出 JSON**：`buildExportPayload()` 已整包导出 `settings`，新字段自动随行；`schemaVersion` 保持 `1`。导出文件含 `adultGate` 属本机设置，不含任何身份信息。

### 4.8 边缘情况（≥3 类，逐条给行为）

| # | 场景 | 行为 |
|---|------|------|
| E1 | 深链接直接访问 `#/detail/accomplice` | 渲染受限占位页 + 弹门；未选择就返回则回商店，不残留半渲染页面 |
| E2 | 已通过后获取并安装，用户随后在设置里关掉 `showAdult` | 商店隐藏，**库页仍显示且可启动**（资产优先于筛选）；不二次弹门 |
| E3 | 成人条目正在下载，用户把 `showAdult` 关掉 | 下载队列继续推进（已排队的任务不因筛选中断），队列页该条目显示 `18+` 标记 |
| E4 | 旧版存档（无新字段） | 三个字段取默认 → `showAdult:true` / `adultGate:'unset'` → 首次点成人卡片时正常弹门，无迁移报错 |
| E5 | 存档被手工写坏（`adultGate: 'yes'`） | `normalize` 丢弃 → 回落 `unset`；不崩溃、不默认放行 |
| E6 | 未满 18 后想再看 | 唯一路径：设置里点该行（重弹门）或清除本地数据；商店无入口（不给未成年人「再试一次」按钮） |
| E7 | 键盘用户 / 屏幕阅读器 | `role="dialog" aria-modal="true"` + `aria-labelledby` 指标题；Tab 在两个按钮间循环；Esc 关闭；焦点回到触发卡片 |

### 4.9 视觉与无障碍要求（交付给林绘澄/程基岩的硬约束）

- 卡片左上角 `18+` 角标：文字标签，不只用颜色；对比度 ≥ 4.5:1。
- 受限占位页：不用模糊打码做噱头，只显示作品名 + 类型 + 「需要年龄确认」+ 一个按钮。
- 弹窗出现时背景 `aria-hidden` 不启用（避免读屏丢失锚点），但焦点必须锁在弹窗内。

| 铁轨尽头 | 西部开放世界 | 最大体积（42 GB），验证下载时长、GB 显示、详情页事实表 |
| 灰线 | 军事 FPS | 第一款「射击」类目，验证新类目 tab 与标签检索 |
| 静帧 | 工具（非游戏） | 验证「软件类目」：`获取/安装/启动` 三个阶段文案对非游戏是否成立 |
| 投币洗衣房 | 经营模拟 | 与「轨道市集」同分类不同调性，验证分类聚合不会串味 |

**验收要点**
1. 18 卡片网格（6 列）不塌行、不缩略走形；焦点推荐区底图与卡片截断正常。
2. 分类 tab 生效，且 tab 计数 = 当前筛选后条数。
3. 「静帧」在详情页显示「类型：工具（非游戏）」，获取按钮文案建议为 `免费获取`（与游戏一致，但事实表加注），**不建议**为工具单独造词。
4. 搜索索引改用 `data-id` 匹配（现有实现按 `GAMES[i]` 与卡片顺序对位，加入分类筛选后会错位）。
5. 商店页头部文案 `6 款虚构游戏` 必须改为动态 `GAMES.length`。
6. 素材可先不交付：12 款新 id 无 `assets` 文件时由 `shell.js` 全局 error 捕获降级为 emoji+渐变（现成机制），A 批允许全占位上线。

### B 批：调性与题材（4 款）

| 款 | 类型 | 为什么放这一批 |
|----|------|----------------|
| 第九次醒来 | 类魂动作 | 高难度标签的文案尺度（不喊「魂系神作」） |
| 棍下留人 | 东方神话动作 | 神话体系的世界观规则与原创性审视 |
| 晒谷场 | 民俗恐怖 | 与「第七走廊」并排比对，验证双恐怖不撞调性 |
| 一格山河 | 4X 策略 | 唯一策略款，验证单品类目的相（见 3.4 风险） |

**验收要点**
1. 与现有 6 款**并排截图**审视：调性是否统一（虚构、克制、冷幽默），有无突然的营销体或中二句。
2. 恐怖两款并排：封面配色一冷紫一暖褐，恐惧来源一文一野，不得出现相似的屋宇/走廊主视觉。
3. 「动作」类目三款同屏时，钩子不得句式雷同（当前三条分别为「次数句」「数量句」「对比句」，已刻意错开）。
4. 评分区间校验：新增款全部 ≤ 4.8，确保 `pickFeatured` 仍稳定返回《云朵烘焙坊》(4.9)，焦点推荐不因扩容而漂移。

### C 批：交互与分级（4 款）

| 款 | 类型 | 为什么放这一批 |
|----|------|----------------|
| 残局守则 | 战术射击 5v5 | 竞技型标签与「经济局」概念文案，依赖筛选体系已稳（A 批） |
| 一招半式 | 武侠刀战 | 与「棍下留人」在同批形成东方动作对照（刀 vs 棍） |
| 代签人 | 叙事互动 | 多线/回溯的文案尺度，与「回声档案馆」形成叙事对照 |
| 同谋 | 18+ 成人向 | 年龄门完整链路，依赖分类与筛选 UI 已定型（A 批） |

**验收要点**
1. 年龄门五条链路：首次通过 / 首次拒绝 / 拒绝后从设置重开 / 通过后关闭显示 / 清除数据后回到未确认。
2. 三轴筛选组合抽查 ≥ 6 组（含「恐怖 + 隐藏 18+ + 未拥有」这类跨轴组合）。
3. 深链接 `#/detail/accomplice` 直访必须出现受限占位页，不得闪现任何截图。
4. 键盘可达性：Tab 顺序、Esc 关闭、焦点回收、读屏标题可读。
5. 事件日志三条 `adult_*` 事件落盘，导出 JSON 含新 `settings` 字段。

**分批顺序的理由（可调）**：年龄门是本次改动里唯一的**新交互机制**，放在 C 批意味着它要等 A/B 的筛选 UI 定型。若主理人希望**风险前置**，建议把「同谋」提到 A 批、把「静帧」挪到 C 批——这样最早一批就能验证最难的分级链路，但代价是 A 批同时要动筛选与门禁，返工面更大。**两种都可接受，需主理人拍板（见 §8 D5）。**
