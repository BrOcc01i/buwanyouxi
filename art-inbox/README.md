# 出图投递目录

按游戏名分四个子目录，把 GPT 生成的**原图**丢进去即可，不用自己裁、不用改格式、不用转 webp。

```
art-inbox/
├─ rail-end/       铁轨尽头     icon · portrait · header · library-hero · screenshot-01..03
├─ grey-line/      灰线         同上
├─ coin-laundry/   投币洗衣房   同上
└─ stillframe/     静帧         同上
```

命名能对上最好（`header.png`、`screenshot-02.png`），对不上但目录放对也能认。
出图后请先自己扫一眼有没有冒出来的文字——有字的重生成，别留着。
