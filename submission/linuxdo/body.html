不玩游戏

一个完全离线的虚拟游戏客户端

这是什么

一个在浏览器里打开就能用的游戏客户端：商店、库、下载队列、安装进度、徽章、体验报告，整套东西都在——

但没有一件是真的。不联网、不下载真实文件、不启动外部程序。六款游戏、评分、获取人数，全部是本地虚构常量。

能做什么

  • 逛商店　六款虚构游戏，各有主视觉、截图、标签与简介
  • 加进库　获取后进入下载队列，进度条从 0 爬到 100%
  • 等一遍完整流程　准备 → 下载 → 校验 SHA-256 → 安装 → 创建快捷方式
  • 揭开封面　安装完成那一步单独做了页面，会给你一张「拥有者类型」结果卡
  • 攒徽章　八枚，从「首次下载」到「六款齐收」
  • 送心意　本地虚拟货币，给虚构工作室送 6 / 18 / 66，纯模拟，不涉及支付

它想复刻什么

不是玩游戏，是买游戏、等下载、把东西收进库的那点踏实感。

进度条走得慢的时候，你会发现自己其实在等一句「已完成」。

技术

客户端Electron + Vite
渲染层原生 JS，无框架
数据只写 localStorage
网络请求零

桌面版是 Windows 安装包；网页版是同一套渲染层直接跑，功能一致。清空数据一键回到初始状态。

离线体验 模拟下载 徽章 无账号 无后端
与任何第三方游戏平台无隶属、无授权关系；界面与素材均为原创生成，不含任何第三方商标或素材。
打开即玩，进度保存在浏览器本地，随时可清空。
