# 原创素材来源说明

批次 3 · 2026-09-05 · 本目录全部素材均为本项目原创产出，不含任何第三方版权内容。

## 生成方式

- **42 张游戏位图（webp）**：由 WorkBuddy 内置 AI 图像生成（文生图）按每款游戏题材定制产出。
  每款游戏生成 3 张底图（竖版主视觉 1024×1536 + 两张横版场景 1536×1024），
  再由 Python PIL 后处理居中裁切/缩放到规格精确尺寸（§9），转 webp（quality=82）。
- **6 个 logo.svg**：手写矢量文件（渐变文字 + 副标题），无位图成分。
- **应用图标 app/icon.png（256×256）与 app/icon.ico（256/128/64/48/32/16）**：
  PIL 程序化绘制（深色圆角底 + 蓝色描边 + "不"字，微软雅黑粗体渲染），保留"不玩游戏"品牌识别，未参考 Steam 图标。

## 提示词设计约束

- 每款游戏按题材独立设计（像素采矿 / 治愈烘焙 / 霓虹竞速 / 恐怖走廊 / 太空贸易 / 记忆档案），不强制统一画风。
- 全部提示词显式禁止 text / letters / words / logo / watermark；位图内不得出现游戏名。
- 提示词与生成记录（18 次调用 + 2 次补生成）留存于开发过程记录，底图源文件在交付后清理。
